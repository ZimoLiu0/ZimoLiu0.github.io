Data-driven Microscopy

Machine Learning-Assisted TEM Analysis of Nanocrystal Superlattices

Mapping subtle structural variations in TEM images using local Fourier fingerprints and unsupervised learning.

Scientific motivation

Subtle changes in nanocrystal packing can be difficult to distinguish by eye in transmission electron microscopy. Local Fourier analysis provides spatially resolved descriptors for comparing structure across an image.

My contributions

Developed and implemented a Python workflow that extracts local TEM image patches, builds FFT-based fingerprints, reduces dimensionality, and clusters the results with Gaussian mixture models.

Methods

  • Transmission electron microscopy image processing
  • Local fast Fourier transform fingerprints and dimensionality reduction
  • Gaussian mixture clustering and phase-map reconstruction

Selected results & status

The workflow produced spatially resolved phase maps for identifying subtle structural variation, phase boundaries, and heterogeneity. The software was registered for copyright at Brown University, and a manuscript is in preparation.
